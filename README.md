Description

This repository contains a collection of C programs created and managed using Git and GitHub. It demonstrates commonly used algorithms and programming concepts.

Programs
Bubble Sort (bubble_sort.c)
Sorts an array of elements using the Bubble Sort algorithm.
Linear Search (linear_search.c)
Searches for a given element in an array using Linear Search.
Factorial (factorial.c)
Calculates the factorial of a number using recursion.
File I/O (file_io.c)
Demonstrates basic file reading and writing operations in C.
Matrix Multiplication (matrix_multiplication.c)
Performs multiplication of two 2×2 matrices.
Prime Number (prime_number.c)
Checks whether a given number is a prime number.
How to Compile and Run
Using GCC

Compile a program:

gcc filename.c -o filename

Run the program:

./filename
Examples
gcc bubble_sort.c -o bubble_sort
./bubble_sort
gcc linear_search.c -o linear_search
./linear_search
gcc factorial.c -o factorial
./factorial
gcc file_io.c -o file_io
./file_io
gcc matrix_multiplication.c -o matrix_multiplication
./matrix_multiplication
gcc prime_number.c -o prime_number
./prime_number
