## About This Repository
This repository contains a collection of C programs created and managed using Git and GitHub. It demonstrates commonly used algorithms and programming concepts.

## List of Programs

1. **Bubble Sort** (bubble_sort.c)
   - Sorts an array using Bubble Sort.

2. **Linear Search** (linear_search.c)
   - Searches for an element in an array.

3. **Factorial** (factorial.c)
   - Calculates factorial using recursion.

4. **File I/O** (file_io.c)
   - Demonstrates file reading and writing.

5. **Matrix Multiplication** (matrix_multiplication.c)
   - Performs multiplication of two matrices.

6. **Prime Number** (prime_number.c)
   - Checks whether a number is prime.

## Requirements
- GCC Compiler
- Git

## How to Compile and Run

Example:

    gcc bubble_sort.c -o bubble_sort
    ./bubble_sort

For other programs, replace the filename.
